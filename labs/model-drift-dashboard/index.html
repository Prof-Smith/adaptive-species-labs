The question

When does an old model stop seeing the present?

A model can be right enough for a while and then gradually become wrong. Drift is dangerous because the model fails slowly, often while people still trust it.

Lab rule:
A model is not a truth machine. It is a map that must be checked against changing terrain.
Step 1
