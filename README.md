# Adaptive Species Labs

A GitHub Pages-ready companion site for *The Adaptive Species* classroom labs.

The Chapter 8 lab includes a detailed guide, improved payoff matrix spacing, all strategy rules, accidental flips/noise, temptation payoff, stress-test explanation, and a discount factor / shadow-of-the-future control.

## Deploy using GitHub Pages

1. Create a GitHub repository, for example `adaptive-species-labs`.
2. Upload all files in this folder to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save.
