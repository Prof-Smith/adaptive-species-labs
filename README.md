# Adaptive Species Labs

A GitHub Pages-ready companion site for *The Adaptive Species* classroom labs.

## Labs, ordered by chapter

- Chapter 1: Decision in the Fog
- Chapter 6: Prediction Under Change
- Chapter 8: Cooperation Under Selection
- Chapter 12: WAIT Before You Trust
- Chapter 13: Ignorance Inventory

The Chapter 6 lab is an Arcas-inspired artificial life simulation that compares random, reactive, and predictive agents in a moving opportunity landscape.
